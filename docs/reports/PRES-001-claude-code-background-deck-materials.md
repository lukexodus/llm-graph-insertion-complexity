## Executive Summary

Prepared the repo-side materials for a **separate background-concepts HTML
presentation** for the defense panel. No HTML was built; this task consolidates
the facts, requirements, style references, and assets the APC needs to plan and
specify that deck.

Luke's fixed choices are recorded:

- 18–22 minutes, about 20 scenes.
- Content stops at **background concepts + research gaps + research questions
  + conceptual framework**. No Chapter 4 results, gates, rankings, or measured
  numbers.
- One self-contained `background-concepts.html`, offline, no CDN/frameworks.
- Click-to-advance reveal steps + scene-jump overview menu; no speaker-notes
  panel and no print mode.
- MMSU green/white/gold style aligned with the existing `.pptx`.

The APC retains **all creative control**: scene composition, copy, visual
metaphors, and animation design. The materials here are a factual base and
constraint set, not a storyboard.

### Key content decisions in the pack

- The background deck uses one running illustration: existing graph
  `Arrays`, `Loops`, `Recursion`, `Trees`, `Sorting`; new concept
  `Binary Search Tree`. It is explicitly labeled an illustration, not thesis
  data.
- The pack records the traps that must survive any rewriting:
  - Funk et al.'s 22–50 prompts is their **pruned** algorithm, not brute force.
  - S2 is uncapped and can produce an empty shortlist.
  - S3 and S4 both cap at 10, so the comparison cannot fully separate bucket
    geometry from shortlist size.
  - RQ4 tests a single-insertion **premise**, not EraRAG's amortized theorem.
  - The `.pptx` model-version label and reference-range numbering are
    inconsistent with the thesis; the background deck avoids both.
  - Say "none of the studies we reviewed", never "nobody has ever".
- The pack deliberately excludes all Chapter 4 results and the post-hoc
  ranking/gates framework.

### Why no HTML was built

Luke's instruction is that the APC owns the creative work and writes the build
specification/prompt; a local agent will implement it later. This task stops at
the materials and constraints.
