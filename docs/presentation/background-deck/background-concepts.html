Strategy 4: folders

bucket

A new item goes into one folder. Only that folder gets searched.

random hyperplane

bit

Each idea gets a 0 or 1 by its side of the wall.

binary code

Similar ideas land on the same side of most walls, so their codes are alike.

12 walls = 12 bits = 4,096 possible codes, more than the 2,000-idea maximum.

Gray order

Codes line up in a row, neighbours differing by one bit.

bounded

The row is cut into folders of 5 to 10 ideas; an oversize folder splits in half, an undersize one joins its closest neighbour.

The new idea gets its code and drops into its home folder; only that folder’s members go to the AI.

How sure is an average?

At each map size, the cost run had 10 trials.

The mean is one estimate from just 10 tries.

bootstrap: reuse the 10 trials. Draw a new set of 10 with replacement.

resample: one such draw. Repeat 10,000 times with a fixed seed, one mean each.

Sort the 10,000 means. The 2.5th and 97.5th percentiles cut off the tails.

The middle 95% is the 95% bootstrap interval.

It shows how much the mean could wobble. It is not a promise; 10 trials is small, so the range can be wide.

What is still missing

Others have narrowed candidates before. What is still missing?

research gap

Gap 1

aggregate

Studies report one total for a whole experiment. None of the studies we reviewed measures what one insertion costs as the map grows.

Gap 2

head-to-head like-for-like

Each system is tested whole. None of the studies we reviewed compares the narrowing methods head-to-head, like-for-like.

literature search

Our search was structured, but not exhaustive. So we say: none of the studies we reviewed.
